# Domain docs

This is a single-context project.

## Read before exploring

- Read `CONTEXT.md` for the current project context and vocabulary. It is the legacy context file; keep using it until a dedicated glossary is created.
- Read relevant decisions in `docs/adr/`.

## Use the project’s vocabulary

Use terms as defined in the project context. If a concept is missing, note the gap instead of silently introducing a competing term.

## Flag decision conflicts

If proposed work conflicts with an ADR, call out the decision and explain why it may need to be revisited.
