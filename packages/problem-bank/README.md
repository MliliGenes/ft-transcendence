# Problem versions

Problem IDs identify the judge contract stored in matches and submissions.
Keep published definitions available for restart recovery. Changes to drivers,
inputs, expected outputs, or scoring require a new problem ID.

`even-ledger` preserves the original Python snippet contract.
New matches select `even-ledger-v2`, which uses standard I/O for C++, C, and Python.
The active matchmaking pool is defined in `services/game/src/game/game.service.ts`.
